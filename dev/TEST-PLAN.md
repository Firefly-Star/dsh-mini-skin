# mini-skin 手测手册（照着点就行）

**怎么用**：从上往下走，别跳。每步都写好了「点哪里 → 看什么 → 什么算过」。过了打个勾继续；不过就**立刻停下**，用最后的 §11 模板记一条发我。
全程大约 60–90 分钟。中途可以随时停，我会给每步编号，你报告时直接说编号（如 `M-14 挂了`）。

**准备**：
- 打开设置 → 左侧「自定义皮肤」。
- 开一个记事本准备记。**每步失败时先记：编号 / 你在哪个状态（深色还是浅色、空闲还是工作）/ 你做了什么 / 看到什么 / 应该是什么。**
- 一个提醒：**别用 F12 看属性、变量、localStorage**——那是我出问题后才用的。你就当自己是第一次用这个插件的普通用户，只信眼睛看到的。

## 2. 通用手感：对**每一个**控件都过一遍（最重要的一节）

> 这一节你就是挨个折腾控件。下面 5 条适用于**所有**下拉、开关、滑块、数字框、按钮。任何控件在这 5 条里挂了，都记一条。
> 别怕点坏——这些操作都是正常用户会做的，挂了就是缺陷。

| # | 做什么 | 什么算过 |
|---|---|---|
| M-04 | 动一下控件，**不关面板** | 界面**立刻**就变了，不用刷新、不用重开面板 |
| M-05 | 关掉设置弹窗 → 再打开 | 控件显示的还是你上次设的值（不是旧值、也不是默认值） |
| M-06 | 刷新页面（F5）→ 再打开面板 | 值还在，界面效果也还在 |
| M-07 | 带开关的行：把开关关掉再打开 | 关掉时**下半截整行消失**（不是变灰、不是变空）；打开时整行回来**且带着你上次设的值** |
| M-08 | 数字框：输入比上限大的值（如 150）回车；再输入负数回车；再清空后点别处 | 150 夹到上限；负数夹到下限；**清空后回到原值，不是 0**（这个曾经真出过 bug） |

## 4. 主内容背景

| M-16 | 把「主内容·有背景图」**关掉** | 主内容背景图消失（露出底色）；**背景图和两行不透明度整行隐藏** |

| M-19 | 下拉选「本地文件…」→ 在弹窗里挑一张图（jpg/png/webp） | 描述行变成「已选择本地文件：xxx」；主内容背景**真的换成这张图** |
| M-20 | 再来一次，但在文件弹窗里点**取消** | 选择保持原样，界面不动，状态行不报错 |
| M-21 | 选过本地图后，切到「不要背景图」，然后 **F5** | 图消失，刷新后也不回来（不残留） |
| M-22 | 在 内置素材 → 本地文件 → 不要背景图 之间来回切 3 轮 | 每次下拉显示的选择和界面上的图**一致**。特别试：选到「不要背景图」后，**再点一次「不要背景图」**，界面应该还是没图、不能卡住 |
| M-23 | 不透明度滑块拖到 **100 / 52 / 0**，各截一张图对比 | 100 图最清楚；0 图被底色完全盖住（看不见图）；52 介于中间 |
| M-24 | 数字框输入 52 回车 | 滑块跟着跳到 52（两者是同一个值）；界面同步变 |

| # | 做什么 | 应该看到 |

## 11. 出问题了怎么报给我

一条一个问题，复制下面这段填空发我就行：

```
编号：M-xx
状态：深色/浅色 · 空闲/工作 · 我正在编辑哪一套
我做了什么：（按顺序写，比如"打开设置 → 自定义皮肤 → 主内容有背景图关掉 → 再打开"）
我看到的：（尽量具体，比如"描述行显示尚未选择图片，但点下拉选本地文件后图没出来"）
我以为应该是：M-xx 里写的预期
能否重现：每次都这样 / 试了3次出现1次 / 只出现一次
截图：（有就贴，没有也行）
控制台：（如果 F12 Console 里有红色报错，贴一行；没有就说没有）
```

**报之前先自查这 3 条**，能省不少来回：
1. 刷新一次页面，看还在不在（排除偶发/热更新干扰）。
2. 确认你处于哪一套预设——很多"没生效"其实是改到了另一套（看「正在编辑」）。
3. 换一个控件试同一个现象（比如"图不显示"是只有本地图不显示，还是内置图也不显示）。

**什么时候可以顺手看一眼 F12**（只在这三种情况下，其它情况别去翻）：
- "选了本地图但图不显示" → 看那个图层的 `background-image` 是不是 `url("blob:...")`，如果显示 `url("undefined")` 或空的，把截图给我。
- "切官方皮肤/卸载后界面有残留" → 看 Console 有没有红色报错，把那条贴给我。
- "导出的包里少了我设的本地图" → 告诉我少了哪一张（主内容/侧栏/顶部），哪个状态。

## 12. 两件想让你拍板的

1. 面板上的**数字框**和**滑块**是同一个值的两个入口，交互上你觉得是"两个都要留着"，还是只留数字框更清爽？——这不算 bug，是我想知道你的手感。
2. 两个标签页**不互相同步**（M-65），你希望它同步吗？现在这会记成"已知行为"，不是缺陷。
